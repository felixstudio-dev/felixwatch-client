# Security Policy

There is no publicly supported Client version yet. Do not include credentials,
tokens, secret configuration, internal evidence or customer data in issues,
reproduction steps or public discussions. For a suspected vulnerability,
contact the maintainer through an independently verified private reporting
channel; no email address or private disclosure endpoint is promised here.

Candidate components must undergo least-privilege, tenant/site isolation,
authentication, replay protection where relevant, resource/timeout and
dependency/license checks, verified builds and a release-specific review.
Monitoring permission never implies rights to execute SSH commands, deploy,
restart services or remediate automatically.
